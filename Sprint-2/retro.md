# Retrospectiva - Sprint 1: Soberano Distrito Barber

##  Dinámica de Evaluación (Estrella de Mar)

### 1. ¿Qué hicimos bien? (Continuar haciendo)
* Definimos con claridad la temática y el público objetivo de la barbería en el archivo `README.md`.
* Realizamos una investigación sólida de 5 referentes reales del mercado, lo que dio una base conceptual firme.
* Logramos estructurar correctamente el repositorio en GitHub separando los entregables por carpetas de Sprints.

### 2. ¿Qué hicimos mal / dificultades? (Dejar de hacer)
* Tuvimos pequeños tropiezos iniciales al vincular Git localmente con el repositorio remoto de GitHub debido a conflictos de historiales no relacionados, lo que retrasó la primera subida.

### 3. ¿Qué deberíamos empezar a hacer?
* Configurar el tablero de GitHub Projects desde el inicio de cada sprint para gestionar las tareas de manera más visual y organizada.
* Planificar los wireframes de las vistas antes de estructurar el código base para agilizar el diseño visual.

### 4. ¿Qué deberíamos dejar de hacer?
* Dejar la inicialización y vinculación de Git para el final del proceso de documentación.
